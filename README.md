# MISRULE

> 你被派去一棟物理規則失靈的建築值班。你可以改寫物理，但房間會記住你怎麼做。

MISRULE 是一款單人 3D 物理沙盒 × Roguelite × 混亂模擬遊戲（Godot 4.3，GDScript）。
每一輪（run）有 3 個班次（shift），一輪約 4–7 分鐘：

1. **抽異常卡**：從 3 張異常卡中挑一張，它會改變這個班次的世界。
2. **接任務**：系統隨機產生主要任務與加分任務（已驗證可完成、有多種解法）。
3. **篡改物理**：隨時用 Q 選單或 1–5 鍵改寫五條物理規則。
4. **連鎖反應**：讓物件互相撞擊、觸發按鈕、風扇、絆線、彈簧板……
5. **結算**：效率、創意、混亂、完成度四項評分 → 稱號 → 解鎖 → 下一輪。

## 執行方式

1. 安裝 [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/)（標準版，非 .NET）。
2. 開啟 Godot → Import → 選這個資料夾的 `project.godot`。
3. 按 F5 執行。

不需要任何外部素材：模型由程式產生（low-poly），音效在啟動時即時合成。
中文字型使用系統字型（Windows 的微軟正黑體）。

## 操作

| 按鍵 | 功能 |
|---|---|
| WASD / 方向鍵 | 移動 |
| 滑鼠 | 視角（點一下畫面鎖定滑鼠） |
| Space | 跳 |
| Shift | 跑 |
| 左鍵 | 抓取物件；拿著時再按一次丟出（越輕丟越遠） |
| 滾輪 | 調整手上物件距離 |
| 右鍵 | 衝擊波（推開前方物件） |
| E | 互動（按鈕、開關） |
| Q | 開啟物理規則選單（世界不會暫停） |
| 1–5 | 快速切換 重力 / 彈性 / 磁性 / 摩擦 / 時間 的下一個等級 |
| Tab | 狀態面板（任務、偏差值、房間的反應） |
| Esc | 暫停 |
| F11 | 全螢幕 |

## 五條物理規則

| 規則 | 等級 |
|---|---|
| 重力 GRAVITY | 正常 / 低 / 高 / 反重力 /（解鎖）橫向 |
| 彈性 BOUNCE | 正常 / 無彈性 / 高 / 極端 |
| 磁性 MAGNETISM | 關閉 / 吸引 / 排斥 / 只吸金屬（＋強度 弱/中/強） |
| 摩擦 FRICTION | 正常 / 黏 / 滑 / 拼布地板（每塊地磚不同） |
| 時間 TIME | 正常 / 慢 / 快 / 不穩定 |

每條規則都有自己的顏色、畫面濾鏡、粒子與合成音效。任務計時使用真實時間，
所以慢動作好用，但會花掉你的時間。

## 核心系統

- **偏差值 Deviation（0–100）**：世界偏離正常的程度，分為 正常 / 不穩定 / 扭曲 / 危急 / 災難 五級。
  有防刷機制：撞擊、連鎖、破壞各有會回充的額度；同一對物件 2 秒內只算一次；物件被撞多了會「無聊」；
  房間自己產生的混亂只能把偏差值推到一個「軟上限」，要更高必須主動改規則與出手。
- **連鎖反應追蹤**：記錄「誰撞了誰、觸發了什麼」，有去重與冷卻，結算時顯示最長連鎖。
- **世界突變**：偏差值升級時觸發（重力反轉、冰地板、強風、體積變化、易碎、磁力配對、天花板崩落……），
  提前 2 秒預告，結束後自動還原（若你期間沒自己改過那條規則）。
- **異常卡組**：12 張資料驅動的異常卡，部分組合有特殊名稱並記錄在圖鑑中。
- **任務系統**：8 種任務（運送、不用手碰、平衡、漂浮、反重力、連鎖觸發、碰撞次數、生存），
  依難度產生並驗證；若產生失敗會退回保證可完成的任務。
- **評分與成長**：四項評分、等級、8 種「混亂人格」、解鎖條件、災難圖鑑、連鎖名人堂。
- **「房間在看你」**：房間會記住你的習慣（最愛的規則、常用風扇、總是親手搬目標、亂丟東西……），
  在班次開始時公開宣告它的反制（例如「風扇被搬走了」），每班最多兩項，Tab 面板隨時可查。
  不做隱藏作弊。

## 測試

```bash
godot --headless --path . --import                 # 第一次需要先匯入
godot --headless --path . --fixed-fps 60 -s res://tests/run_tests.gd
```

目前 127 項自動測試（規則、偏差值防刷、連鎖、裝置、任務驗證、整輪流程、存檔損毀復原、效能等）。
另外有兩個工具：

- `tools/balance_probe.gd`：模擬玩家 90 秒，印出偏差值與破壞速度（參數：`卡片ID [verbose] [casual] [magnet] [idle]`）。
- `tools/screenshot.gd`：用真的渲染器截 10 張圖（需要顯示環境或 xvfb）。
